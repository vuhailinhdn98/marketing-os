Mã Nguồn Google Apps Script (Dán vào Google Sheet trong 30s)

  1. Mở file Google Sheets của bạn, chọn menu: Tiện ích mở rộng (Extensions) → Apps Script.
  2. Xóa code mặc định và dán đoạn mã bên dưới vào.
  3. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → Chọn loại: Ứng dụng web (Web app).
  4. Đặt quyền truy cập: "Bất kỳ ai" (Anyone) → Bấm Triển khai → Copy URL dán vào ô Cấu hình ở trên.
